# Replication materials

This repository contains replication materials for the Master’s Major Research Paper:

**“Economic power and geopolitical shifts: Is China’s economic engagement reshaping foreign policy in Central America and the Caribbean?”**

## Repository structure

- `/data`: Input datasets used in the analysis  
- `/code`: R scripts for data processing, analysis, and figure generation  
- `/output`: Generated tables and figures  

Large datasets that exceed GitHub’s file size limits are archived separately on Zenodo (DOI: https://doi.org/10.5281/zenodo.18425311). See `/data/README.md` for details.

## Replication instructions

Before running the scripts, set the working directory to the **root of this repository**.

In RStudio, this can be done by:
- Opening the repository folder as an RStudio Project, or
- Setting the working directory manually to the repository root

Once the working directory is set:

1. Open R or RStudio
2. Navigate to the `/code` directory
3. Run the scripts in numerical order

All file paths in the scripts are specified relative to the repository root.

## Software requirements

- R version ≥ 4.2
- Required packages are listed at the top of each R script
