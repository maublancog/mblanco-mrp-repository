Data

This folder contains datasets used in the quantitative analysis for the article:

**“Economic power and geopolitical shifts: Is China’s economic engagement reshaping foreign policy in Central America and the Caribbean?”**

## Data availability

Due to GitHub file size limitations, not all raw datasets are stored directly in this repository.

- Datasets smaller than 100 MB are included in this folder.
- Three large raw datasets (exceeding 100 MB) are archived on Zenodo and can be accessed at the following DOI:

https://doi.org/10.5281/zenodo.18425311

## Replication instructions

To replicate the analysis:

1. Download the archived datasets from Zenodo using the link above.
2. Place the downloaded files in this `/data` folder.
3. Run the R scripts in the `/code` directory in numerical order.

All file names should remain unchanged to ensure compatibility with the scripts.

## Notes

The datasets hosted on Zenodo are provided in their original format and are used as inputs for data processing and analysis. Any transformations or cleaning steps are documented in the corresponding R scripts.
